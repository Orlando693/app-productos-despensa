# App de productos de la despensa 

## Integrantes

  Claure Collao Sebastian 
  Moreno Cors Orlando Sebastian  

## Tipo de proyecto

Aplicación web para la gestión de productos de la despensa del hogar.

## Modalidad

Proyecto académico desarrollado de manera grupal.

## Problema inicial

Las personas compran productos que ya tienen en casa o descubren demasiado tarde que algún producto se terminó.

Antes de ir al supermercado, muchas personas no tienen tiempo de revisar toda su despensa o refrigerador, lo que puede provocar compras innecesarias o que se olviden productos importantes.

## Uso de Inteligencia Artificial

El proyecto será desarrollado sin el uso de herramientas de Inteligencia Artificial.
