# Mejora pantalla listas

## Antes

La pantalla inicial tenía toda la información junta,
sin diferenciar la acción principal.

## Cambio

Se separaron las tareas:
- Ver listas
- Crear lista
- Gestionar productos

Se aplicó una escala de espaciado basada en 8px.

## Después

El usuario identifica primero sus listas
y la acción principal.
